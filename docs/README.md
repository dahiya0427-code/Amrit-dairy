| 02 | [User Personas](02-user-personas.md) | Audience per growth stage (Sonipat → 50 km → 100 km → India), 5 personas, shopping behaviour, feature priorities |
| 03 | [Brand Guidelines](03-brand-guidelines.md) | Logo system, colour palette (contrast checked), bilingual typography, e-commerce UI components, imagery, voice |
| 04 | [Product Requirements (PRD)](04-product-requirements-document.md) | Functional requirements for catalogue, checkout, Razorpay, subscriptions, SEO/AEO/GEO, architecture, Shopify migration |
| 05 | [Website Architecture](05-website-architecture.md) | Sitemap, URLs, Shopify 301 map, navigation, page-by-page blueprints |
| 06 | [Google Stitch Prompts](06-google-stitch-ui-prompts.md) | Master design brief + 16 screen prompts + QA checklist |
| 07 | [Phase-wise Execution Plan](07-phase-wise-execution-plan.md) | Phases 0–5, sprints, team, budget guide, risks, next steps |

**Legend used in the docs:** ✅ taken from the live site · 🟡 to be confirmed by the owner · ⚠️ risk or issue to fix.
